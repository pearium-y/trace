# 循迹 Trace

> 纸页之间，看见坚持的痕迹。

一个纸感手账风的习惯与计划追踪应用：创建习惯、每日打卡、热力图回顾、周期性分析报告，帮助养成并坚持习惯。纯前端应用，数据仅保存在浏览器本地，无需服务器与账号。

## 功能特性

### 计划管理
- **两种频率**：每日 / 每周
- **三种目标类型**：
  - 完成次数型（如：每日读书 1 次）
  - 时长累积型（如：每周跑步 2 小时）
  - 无目标（单纯打卡记录）
- 每个计划可自定义名称、emoji 图标与主题色，创建时实时预览卡片样式

### 记录打卡
- 录入数值对应计划目标（次数或分钟数）
- 同一天多次录入只更新当天数值，**不会累加**
- 支持补录任意一天的记录（点击热力图格子即可）
- 可为每条记录添加备注，细化完成情况说明
- 快捷 +1 打卡与盖章动画反馈

### 数据可视化
- **单计划热力图**：GitHub 风格年度网格，颜色深浅反映当日完成度，点击任意格子可补录
- **周 / 月 / 年三维度报告**：
  - 热力图与柱状图
  - 完成率、连续天数、累计统计
  - 备注回顾（汇总周期内所有记录备注）

### 数据备份
- **JSON 导出**：完整数据备份，可用于跨设备迁移
- **JSON 导入**：从备份文件一键恢复
- **CSV 导出**：全部记录明细（带 UTF-8 BOM，Excel 直接打开不乱码），可用表格软件二次分析

### 其他
- 移动端优先设计（底部 Tab 导航），桌面端自适应（侧栏导航）
- 无目标计划打卡即完成；周计划按整周累计值判定达成
- 连续天数统计（每日计划按天、每周计划按周）

## 技术栈

| 类别 | 技术 |
|---|---|
| 框架 | React 18 + TypeScript |
| 构建 | Vite 5 |
| 日期处理 | dayjs |
| 持久化 | localStorage |
| 可视化 | 手写 SVG（热力图 / 柱状图，零图表库依赖） |
| 样式 | CSS Modules + 全局设计令牌 |

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/<your-username>/trace.git
cd trace

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 本地预览生产构建
npm run preview
```

## 部署

构建产物为纯静态文件，部署 `dist/` 目录到任意静态托管即可：

```bash
npm run build
```

- **Nginx / Apache**：将 `dist/` 内容复制到站点根目录
- **Vercel / Netlify**：构建命令 `npm run build`，输出目录 `dist`
- **GitHub Pages**：可配合 [gh-pages](https://www.npmjs.com/package/gh-pages) 等工具推送 `dist/`（`vite.config.ts` 已配置相对路径 `base: './'`，支持子路径部署）

## 数据说明

- 所有数据（计划 + 记录）存储于浏览器 localStorage（key: `trace-data-v1`），不上传任何服务器
- 更换设备或浏览器时，请在「设置 → 导出 JSON 备份」导出，再到新环境导入
- 「设置 → 清空全部数据」会删除所有计划与记录（需二次确认，建议先备份）

## 项目结构

```
src/
├── App.tsx              # 应用入口与路由（简单状态路由）
├── store.tsx            # 全局状态（Context + useReducer + localStorage 持久化）
├── storage.ts           # 数据解析 / 校验 / 导入导出
├── types.ts             # 核心类型定义（Habit / DayRecord / DB）
├── components/          # 通用组件（热力图、柱状图、记录弹层、底部导航等）
├── pages/               # 页面（今日 / 计划 / 详情 / 表单 / 报告 / 设置）
├── utils/               # 工具（日期、统计、格式化、CSV、下载）
└── styles/              # 全局样式与设计系统
```
